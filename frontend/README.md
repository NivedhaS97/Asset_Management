# Asset Management - Frontend

This is a Vite + React + TypeScript + **Tailwind CSS** frontend scaffold for the Asset Management POC.

Quick start

1. Install dependencies

```bash
cd "c:\Asset Management\Asset_Management\frontend"
npm install
```

2. Run dev server

```bash
npm run dev
```

3. Open the app at the URL shown by Vite (default http://localhost:5173)

Connect to your backend by updating the API base URL in the code (add an API client later in `src/api`).
